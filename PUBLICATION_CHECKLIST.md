# Publication checklist

- [x] GitHub-friendly root directory and standard manifest names.
- [x] Stable plugin identity (`gms-modflow-modeling-assistant`) and semantic version (`1.0.0`).
- [x] Skill renamed from generic `instructions` to discoverable `gms-modflow-modeling`.
- [x] Linked documentation only; no GMS manuals, proprietary binaries, or bundled PDFs.
- [x] Skill clarifies that source links must actually be visited before claiming to have verified a manual instruction.
- [x] English README, MIT license and `.gitignore`.
- [ ] Test installing the plugin/Skill in a **fresh account or environment** with and without web access.
- [ ] Verify that GMS version-specific menu instructions match your actual installed build.
- [ ] Set repository URL and, if desired, maintainership contact details.
- [ ] Consider further icon/license review if the icon derives from third-party artwork.

This checklist documents packaging checks, not a claim of independent runtime compatibility certification.
